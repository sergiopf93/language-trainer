# Auditoría pedagógica C01–C13 para Mixed

Asesoría; no modifica repo ni promociones. Inspeccionados AGENTS/contexto, authoring/model, manifest/engine y todas las actividades C01–C13. Selección manual conservadora por prompt/criterio, no por regex. ID completo = it-a1-c + código + - + key. Versiones de actividad explícitas. «Apto» significa oportunidad pertinente para una faceta, no cobertura exhaustiva ni dominio.

## Condiciones comunes

Todos los conceptos del grupo y cierre transitivo de catalog.prerequisites deben estar introducidos; no exigir dominio. Revisar también requisitos léxicos y de construcción por actividad, que el grafo puede no expresar. Mantener whitelist ID/version y estado editorial homogéneo. Nuevas actividades son candidate; no agregarlas a grupos reviewed bajo motor actual (rechaza estados mezclados). Crear pools candidate coherentes o revisión independiente posterior autorizada, nunca cambiar recibos para eludirlo. Cada grupo necesita 2 actividades diferentes por concepto; matching no cuenta como tres oportunidades. No doble atribución por componentes de la misma respuesta.
