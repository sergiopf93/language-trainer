# Alcance del MVP

Estado: propuesta precisa para aprobación; todavía no autorizada para desarrollo. Cantidades y corte curricular son decisiones de producto H, no una dosis pedagógica demostrada.

## Objetivo

Demostrar aprender → practicar → recuperar → usar → detectar error → revisar → mezclar → observar evidencia. El MVP debe completar varias vueltas del ciclo, incluida comprobación otro día; no pretende cubrir A1 completo.

### Producto e interacción

- Un perfil local, italiano objetivo y español de interfaz/explicación.
- Focus manual, Mixed explicado y Review por necesidad.
- Teoría breve y detalle para los diez objetivos; búsqueda por alias e intención editorial.
- Evidencia por dimensión, ayudas, intentos, errores relacionados y última comprobación.
- Cinco familias: selección significativa, hueco, transformación, producción contextual acotada y lectura con preguntas. La reparación reutiliza estas familias.
- Tres paquetes de lectura y tres encargos de escritura: presentación de compañeros, mensaje de ubicación durante viaje y descripción de personas/objetos cotidianos. Cada paquete mantiene conceptos y léxico dentro del alcance.
- Escritura hasta dos o tres frases guiadas; aceptación de variantes revisadas, error verificable o abstención. No corrección universal.
- Pausa/reanudación, uso local tras primera carga y respaldo/restauración manual versionada.

### Cobertura editorial mínima para publicar

Cada objetivo debe tener explicación, criterios y variantes revisados, práctica con apoyo, recuperación independiente apropiada a su alcance, aplicación comunicativa y material reservado para revisión diferida. Contraste donde exista alternativa conocida; por ejemplo essere/avere y singular/plural. En persona/referente, no forzar una conjugación para medir comprensión.

Reservar por objetivo al menos dos conjuntos equivalentes no expuestos: uno para primera comprobación posterior y otro para una nueva ocasión. Es un mínimo editorial H para poder demostrar temporalidad/variedad, no prueba de suficiencia estadística. Los conjuntos pueden compartir un texto entre objetivos si cada oportunidad está identificada; la misma respuesta no cuenta repetidamente como evidencia independiente. Si se agota reserva, mostrar el límite y no afirmar transferencia nueva.

El conjunto editorial de evaluación incluirá respuestas válidas alternativas, errores objetivo conocidos, errores fuera de alcance, respuestas ambiguas y objetivos ausentes. Debe comprobar tanto falsos rechazos como falsos positivos: detectar una forma correcta no basta para aceptar toda la intención o el mensaje. Un falso positivo conocido que atribuya evidencia indebida bloquea el ítem igual que un falso rechazo. La abstención se mide aparte para evitar que un evaluador que se abstiene siempre aparente calidad.

No se fija una cifra de ejercicios por sesión; se fija cobertura. Antes de desarrollar el banco completo, producir una unidad editorial piloto de essere/avere y una muestra nominal para revisar variantes y carga de autoría. No se producen aún en esta fase de diseño.

## Recorrido de demostración

Primera ocasión: elegir «Essere — presente», intentar sin tabla, consultar explicación si hace falta, recuperar una persona diferente y escribir dónde está un grupo. Si aparece «Noi sono», registrar el error y reparar sin borrar el intento inicial. El cierre indica recuperación observada o apoyo necesario, nunca dominio definitivo.

Una ocasión posterior, separada de la última exposición por el intervalo piloto acordado: nueva situación y sujeto sin recordatorio previo. Después, si avere ya es accesible, elegir entre ubicación y posesión en una sesión mixta. El progreso conserva qué se comprobó y cuándo; si vuelve a fallar noi, priorizar ese patrón y no reiniciar todas las personas. La muestra nominal repite el ciclo con género/plural y comprueba que un error propagado no crea tres penalizaciones.

Este recorrido es un criterio de demostración, no un calendario ni resultado de aprendizaje garantizado.

| Riesgo | Respuesta y condición de parada |
|---|---|
| Diez objetivos generan demasiada autoría | R2 conserva muestra verbal y nominal para probar atribución de errores; si el piloto editorial no es viable, proponer recorte nominal a Sergio antes de ampliar trabajo. |
| Variantes válidas rechazadas | Conjunto editorial con respuestas alternativas; abstenerse ante desconocidas. Falsos rechazos conocidos bloquean publicación del ítem. |
| Banco sin novedad suficiente | Separar familias y exposición; reservar comprobaciones y no simular novedad. |
| Progreso engañoso | Mostrar evidencia/lagunas; política versionada antes de usar «estabilidad». |
| Pérdida de almacenamiento local | Respaldo manual, guardado visible y recuperación verificada durante implementación. |
| Ausencia de revisor lingüístico | No presentar contenido candidato como validado. Resolver responsable y alcance antes de publicar. |
| Piloto personal confundido con eficacia | Separar aceptabilidad, corrección técnica y observación pedagógica; no hacer promesas causales. |
