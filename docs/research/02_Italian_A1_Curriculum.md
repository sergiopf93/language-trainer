# 02 — Italian A1 Curriculum

## 1. Criterio curricular

**REF:** el MCER describe actividades y competencias, no prescribe un índice gramatical de italiano [S15]. Se contrastaron guías CILS, un ejemplo CILS A1 standard, CELI Impatto, programa universitario de Bolonia y un manual reconocido [S16–S20]. Son referencias de cobertura; sus secuencias no prueban un orden óptimo.

**R:** organizar la progresión en espiral: formas frecuentes para comunicar desde el inicio, ampliación de variantes, contraste y reutilización en otros contextos. El orden siguiente es una propuesta, no un orden natural demostrado. No son semanas obligatorias.

Objetivo inicial: entender información cotidiana breve y escribir frases y mensajes sencillos sobre personas, necesidades y actividades. La aplicación centrada en lectura/escritura no puede afirmar que evalúa por completo comprensión oral, interacción oral o pronunciación.

## 3. Núcleo y ampliación: resolver diferencias entre fuentes

**REF:** las guías CILS consultadas incluyen passato prossimo en A1, con distintas exigencias receptivas y productivas; el programa A1 universitario revisado se centra en presente, modales, reflexivos y funciones cotidianas. Nuovo Espresso 1 introduce pasado dentro de su recorrido [S16, S17, S20].

**R:** núcleo prioritario C01–C26 + C29 + léxico transversal, seguido de cantidades, referencias pronominales e instrucciones frecuentes. Ampliación final C31–C33 para relatos breves. Esta organización limita la primera carga, pero no redefine oficialmente A1. Si se decide preparar CILS, revisar específicamente el módulo y sus requisitos actuales.

Conviene diferir la producción sistemática de imperfetto frente a passato prossimo, futuro morfológico completo, condicional más allá de fórmulas, subjuntivo y combinaciones complejas de pronombres. Se pueden comprender expresiones concretas antes de estudiar esos sistemas.

**R para hispanohablantes:** contrastes breves para edad con avere, ser/estar frente a essere/stare, plurales, artículos lo/gli, posesivos de familia y preposiciones por expresión. Son posibles focos de interferencia, no errores inevitables de cada persona.

## 4. Knowledge graph pedagógico

Una flecha significa que el conocimiento anterior hace más accesible la tarea posterior. No obliga a terminar todos los ejercicios del origen. Hay dependencias fuertes y apoyos; esta distinción evita bloqueos artificiales.

| Destino | Dependencias fuertes para práctica sin ayudas | Apoyos útiles / acceso anticipado |
|---|---|---|
| Presente de essere y avere | Personas y significado de las expresiones | Grafía; se pueden usar fórmulas con modelo. |
| Artículos: elección de forma | Género, número si plural, sonido inicial | Vocabulario con artículo memorizado. |
| Artículos: elección determinado/indeterminado | Referente nuevo/identificable y contexto | No depende de saber todo el paradigma. |
| Plural del sustantivo | Forma y clase de sustantivo | Puede aprenderse junto con singular, no después de todo el género. |
| Concordancia del grupo nominal | Género/número, forma del adjetivo y artículo requerido | Essere ayuda para descripciones, pero no para toda frase nominal. |
| Presente regular | Persona + familia verbal + significado | Essere/avere ofrecen contraste, no son requisitos lógicos absolutos. |
| Preposición articulada | Preposición contextual + artículo | Expresiones al bar/del giorno pueden anticiparse. |
| Posesivos productivos | Persona del poseedor + género/número de lo poseído | Léxico familiar; expresiones mio padre como punto de entrada. |
| Reflexivos | Verbo + persona + función del pronombre | Mi chiamo como expresión inicial. |
| Mi piace/piacciono | Referente que gusta y su número; mi como destinatario | Fórmula fija mi piace + infinitivo antes del análisis completo. |
| Passato prossimo | Essere/avere en presente + participio + relación temporal | Expresiones ho fatto / sono andato antes del sistema completo. |
| Concordancia con essere en pasado | Passato prossimo + género/número del sujeto | Participios frecuentes primero. |
| Mensaje breve | Vocabulario del tema + frases + función comunicativa | Conectores mejoran cohesión; no exigir todos para empezar. |

El modelo propuesto en el encargo «artículos → sustantivos» se modifica: nombre y género se introducen juntos y el artículo los refuerza. «Essere/avere → presente» también se matiza: presente es una noción temporal y una familia de formas; se empieza a utilizar al aprender esos verbos.

**R: “¿Qué aprendo después?”** elegir un concepto que sirva a una situación deseada y tenga apoyos suficientes; si aparece un obstáculo, sugerir reparación concreta; si faltan datos, ofrecer una comprobación breve. Ejemplo: recupera essere y plurales, quiere describir su casa → c'è/ci sono; falla gli pero usa il/la → ampliar selección de artículo, no reiniciar toda la gramática.

## 6. Evidencia de progreso curricular

**R:** al terminar cada tramo, comprobar dos cosas distintas: uso del concepto focal y resolución de una tarea cotidiana. Por ejemplo, dominar formas de artículos no basta para escribir una petición comprensible; un mensaje logrado con fórmulas memorizadas tampoco demuestra todas las concordancias.

Para el conjunto: lectura de aviso nuevo, comprensión de un mensaje personal, escritura de presentación y petición breve, descripción de rutina y, en ampliación, relato de unos hechos. Se pueden llamar «comprobaciones internas de objetivos A1 de lectura/escritura», sin atribuirles certificación oficial.
